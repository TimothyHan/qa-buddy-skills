# SDT Playbook

Shared QA methodology that all QABuddy skills reference. Each file covers one topic and stays under 70 lines. Skills load only the files they need — see `index.md` for the full map.

## Editing

1. Stay within the file's scope — don't add content that belongs in a different file
2. Keep under **70 lines** — if it grows beyond that, split into a new file
3. Write for the AI, not for humans — be direct ("Do X" not "Consider X")
4. Run `node build.js all` after editing — references are copied to all platforms

See [CONTRIBUTING.md](../../../CONTRIBUTING.md) for the full guide on adding playbook knowledge.
