# SDT 플레이북

모든 QABuddy 스킬이 참조하는 공유 QA 방법론입니다. 각 파일은 하나의 주제를 다루며 70줄 이내로 유지합니다. 스킬은 필요한 파일만 로드합니다 — 전체 매핑은 `index.md`를 참고하세요.

## 편집 규칙

1. 파일의 범위 내에서만 편집하세요 — 다른 파일에 속하는 내용을 추가하지 마세요
2. **70줄** 이내로 유지하세요 — 초과하면 새 파일로 분리하세요
3. AI를 위해 작성하세요 — "X를 고려해 보세요"가 아니라 "X를 수행하세요"
4. 편집 후 `node build.js all`을 실행하세요 — 참조 파일이 모든 플랫폼으로 복사됩니다

자세한 내용은 [CONTRIBUTING.md](../../../../CONTRIBUTING.md)를 참고하세요.
